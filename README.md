# Mutual Fund Analytics Dashboard

## Project Overview

This project is a Streamlit-based Mutual Fund Analytics Dashboard developed using Python.

## Features

- Home Dashboard
- Company Profile
- Fund Screener
- Peer Comparison
- Trends Analysis
- Sector Analysis
- Capital Allocation
- Reports
- Valuation Module

## Technologies Used

- Python 3.14
- Streamlit
- Pandas
- Plotly
- SQLite
- OpenPyXL

## Project Structure

```
mutualfundanalytics/

├── src/

│
├── outputs/
├── notebooks/

├── README.md
```

## Run the Project

Activate virtual environment:

```
venv\Scripts\activate
```

Run Streamlit:

```
streamlit run src/dashboard/app.py
```
