
# Mutual Fund Analytics Project

## Project Overview

This project analyzes mutual fund data using Python, SQLite, and Tableau.

## Dataset

* NAV History
* Investor Transactions
* Scheme Performance

## Tools Used

* Python
* SQLite
* Tableau
* GitHub

## How to Run

1. Activate virtual environment
2. Run scripts from the scripts folder
3. Check database using:

python scripts\check_db.py

## Dashboard

* NAV Analysis
* Performance Analysis
* Transaction Analysis
* Category Analysis
